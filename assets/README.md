# assets

Original Merlin Open files, copied and reorganized by `tools/copy-assets.ts`.
Do not edit by hand. The archive they come from is not in this repository.

- `maps/` Lingo property-list map files, mirroring the archive's `maps/` subfolders (`works/`, `not_fully_tested/`, ...) plus `tvsDemo.txt` from `map_to_play/`; a map's id is its path here without `.txt` (`works/sam`). `not_fully_tested/mriv_small.txt` (5x1 rooms, MR4 tilesets) is the main test map; `test_maps/` holds the hand-made test maps (not from the archive): `combat_test.txt` is a 2x1 test map for the combat slice (regenerate with `node tools/make-combat-test-map.mjs`); `enemies_test.txt` (4x1, `node tools/make-enemies-test-map.mjs`) shows the goblin mages and mage hut, the orcs, a goblin hut and the orc house, one room each; `spell_test.txt` (2x1, merlinOpen tilesets, `node tools/make-spells-test-map.mjs`) puts every spell scroll in a row above Merlin, with goblins, an orc and a goblin hut in the room to the right
- `tile-keys/` per-tile collision symbols, 10 tiles per row, 32x32 px
- `map-patches/<map id>.json` (e.g. `map-patches/not_fully_tested/mriv_small.json`) places extra objects-layer symbols on top of a copied original map at conversion time (e.g. goblins in `mriv_small`'s first rooms for testing); the map copy itself stays identical to the original
- `tilesets/` tile sheets extracted from the Director cast with `tools/director-extract/`, 32 px tiles, tiles per row = width/32 (10 for merlinOpen, 7/8 for merlin4 and the MR3 `merlin{Passive,Active,Objects}` sheets); white is transparent on Active/Objects. All are 32-bit cast members (`tools/director-extract/extract_tlk.py`); `merlin4Objects.png` is copied from the archive's clean PNG, which is identical
- `actors/` actor definitions (`act_<name>.txt` in the original), Lingo property lists resolved parent -> child
- `teams/` every team definition (`tem_<name>.txt` in the original): hate groups and priorities, friends, member caps
- `sprites/mer/` (Merlin; folders are named after the actor `name`), `sprites/goblinWarrior/`, `sprites/gar/` (goblin archer), `sprites/gobarrow/` (goblin arrow), `sprites/spell/` 8-bit BMP frames, named `anm_<chr>_<anim>_<delayTicks>_<frame>.bmp`, white is transparent; the goblin grave (`goblin_grave.bmp`, one cast member) is copied as the grave frame of both goblinWarrior and gar
- every other folder under `sprites/` (goblin mage, orcs, huts, skeletons, dragons, ... about 100) holds PNG frames of the engine's Director cast members (`tools/director-extract/dump_bitmaps.py`; the owner's reference bundle ships them as `cast_bitmaps/`), white is transparent, each folder with a `regpoints.tsv` (the members' registration points; the renderer hangs these frames from them). The delay in each frame name is that frame's own (a strip can mix delays); a folder is named after the actor's `#name` even when the members spell it differently (`iceBoulder` holds `anm_iceboulder_*`)
- `sprites/<scroll>/` (armySummon, cBlast, energyBlast, ... every spell scroll) the scroll members from the engine's cast, dumped into `cast_bitmaps/` with `dump_bitmaps.py <key>_scroll <key>_writing <key>_ws`: `<key>_scroll` as the `stand` strip, `<key>_writing` as `writing`. `sprites/mer/` also holds the cast's `magicMelee` and `weaponMelee` strips (energy punch, sword) as PNG with their reg points; `sprites/spellIcons/` the summon stage icons (objSpellIcons)
- `sprites/{manaBurst,manaCapacity,manaFlow,walkSpeed,medikit}/` the pickups' gfx members (`gfx/potions/`, `gfx/medikit/`): `<name>_potion` as the `stand` strip, `<name>_writing` as `writing`; the medikit's also `medikit_on`/`medikit_off` (its HUD icon) as `hudOn`/`hudOff`. `sprites/maxikit/` (no member in `gfx/`): the stand frame cut by `copy-assets` from merlinOpenObjects tile 46 to 16x16, and the medikit's writing
- `exit-arrows/` the 16x16 `arrow_{green,red}_{up,down,left,right}.bmp` exit arrows from the archive's `gfx/background/` (structMaster.structExitArrowMembers), white is transparent
- `hud/` the game screen's `health_bar_surround` (white is transparent, ink 36) and `health_grey_locz151` (the word "health") members, dumped from the engine's gfx cast with `tools/director-extract/dump_bitmaps.py health_` (not in `gfx/`); `hud/weapon-selector/` the weaponSelector members: each weapon's 18x16 `<key>_ws` icon (`punch_ws` for the punch) and the palette's `greenBox_ws` / `yellowBox_ws` (white is transparent)
- `cut-scenes/cut_scene_to_play_at_end.txt` the cut scene played when a map is complete (the cast member `scr_cut_scene_to_play_at_end`, info line included; the archive's `cut_scene_to_play_at_end/` folder that would override it is empty)
- `title/` the title screen's letters (`gfx/title/output/<letter>.gif`; the apostrophe as `apostrophe.png`), converted to PNG; white is transparent
- `keybindings/` original key code bindings (Mac virtual key codes)
- `tuning.json` remake-side overlay applied by `tools/convert-assets.ts` on top of the resolved actor files; not from the archive, edit by hand. The shape is `{ actorKey: { field: value, ..., attack: { field: value, ... } } }`, keyed by actor file key (`goblinArcher` for `act_goblinArcher.txt`) with field names as in the Lingo data. Everything except `attack` is deep-merged into the actor's resolved properties before its starting weapon is looked up, so an overlay can change `weapon`; `attack` is then merged on top of the installed attack (the weapon's, or the natural one). Values must have the original types (a point is `{ "x": 1, "y": 2 }`); a wrong type fails the conversion naming the actor and field. The shipped file gives the player `weapon: energyBlast` (the original grants the blast through a scroll pickup, which most maps lack), and the army summon scroll a `startingArmy` (owner request: the reserve army it brings). Example: `"goblinArcher": { "attack": { "reach": 160 } }` makes the archer shoot from 160 px instead of 100.
- `sounds/` 32 sound effects and `music/` 8 music tracks extracted from the engine's Director file (`tools/director-extract/`); names match the cast members the Lingo plays
- `extracted/bitmaps/` spare cast frames not wired in (spell frames, a duplicate goblin hut grave member), with `regpoints.tsv`
